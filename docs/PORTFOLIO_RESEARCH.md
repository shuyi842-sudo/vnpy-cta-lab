# 固定三品种 CTA：冻结规则后的最终测试

## 研究顺序与独立性

研究范围事先固定为螺纹钢、铜、铝。旧版已使用部分 2024/2025 螺纹钢结果，因此不把这些数据再称为未触碰测试集。

1. 在提交 `edcd758` 中固定协议、品种、风险约束、时间区间和参数网格，并先推送到 GitHub。
2. 完成共享账户、因果换月和封存门槛的合成金融测试，提交研究实现 `8e015de`。
3. 用 2023–2024 开发、2025 验证，在预设 6 组统一参数中选择；选择锁提交为 `3121163`，公开后才下载 2026 归档。
4. 使用选定的 20 日突破、3 倍 ATR 评估 2026 年 1–9 月，不执行参数搜索。首次评估时间、代码/数据哈希和结果保存在公开汇总的测试凭据中。

这是事后历史研究的操作顺序审计，不是在 2026 年之前预注册的预测，也不能证明分析者从其他渠道完全不知道公开市场信息。现在再次运行同一测试只属于复现，不能称为新的独立检验。

### 共享账户的观测

同一账户的名义敞口峰值约为权益的 30.77%，预计保证金峰值约 4.62%，初始止损风险合计峰值约 0.89%。这些是收盘快照，不是盘中峰值。不是三份独立 100 万账户的收益相加，品种贡献之和与组合逐日盈亏一致。

真实样本没有触发资金拒单；资金不足、跳空超预算、旧腿未平、资金释放及缺失行情的行为通过合成金融用例验证，不能将合成用例称为实际市场中的压力测试。

## 限制与复现

保证金统一按 15% 估算，成本为每边成交额万分之一及每边 1 tick；没有逐日还原交易所保证金、经纪商费率、成交容量、涨跌停队列、盘中追保或模拟柜台。收盘止损与下一开盘执行可能承受跳空损失。

固定三个品种中铜铝相关，最终测试仅 181 日、22 笔成交，不足以做长期收益或统计显著性断言。验证期表现本就弱，测试亏损作为结果保留。后续新策略必须使用新的、未用于选择的证据；本项目不会把反复调参后重跑 2026 称作新的样本外结果。

使用 `python scripts/reproduce_portfolio.py` 可按已发表归档 URL 和 SHA-256 重放已冻结研究，并检查每项汇总统计。它不重选参数，不改变原始公开测试凭据。详见根目录 README 的安装与复现说明。
